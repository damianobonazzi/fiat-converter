Privacy Policy for Fiat Converter

Last updated: September 2026

This Privacy Policy describes how Fiat Converter ("the Application") handles user data. The Application is provided as a free, client-side utility tool.

1. Information Collection and Use

Fiat Converter does not collect, store, transmit, or share any personal data, sensitive user information, or device identifiers. All currency conversions and calculations are performed locally within your device's browser or web view environment.

2. External API Requests

To provide accurate currency conversion rates, the Application fetches publicly available market data from third-party APIs. These network requests do not include any user identifiers, account information, or personal tracking data.

3. Local Storage and Caching

The Application utilizes standard web technologies (such as Service Workers and browser LocalStorage) solely to enable offline functionality and cache recent exchange rates. No personal data is ever stored in these local caches.

4. Analytics and Tracking

The Application does not use any third-party tracking, analytics tools, or advertising networks (e.g., Google Analytics, AdMob, or cookies).

5. Children's Privacy

Since the Application does not collect any personal information, it is safe for users of all ages, including children under the age of 13.

6. Changes to This Policy

This Privacy Policy may be updated periodically. Any changes will be reflected directly on this page with an updated revision date.

7. Contact Us

If you have any questions regarding this Privacy Policy or the Application, you can contact the developer via GitHub at: https://github.com/damianobonazzi/fiat-converter.
